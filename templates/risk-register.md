# Risk Register — Appendix A.4

Every risk carries a **trigger** (observable condition with a date) and a
**pre-committed fallback** (the decision, already made). Review weekly; fire
triggered fallbacks; retire dead risks.

| Risk | Likelihood | Trigger | Pre-committed fallback |
|---|---|---|---|
| Dataset falls through | | Data not in hand by week 4 | Switch to named public dataset; rescope claims |
| Ethics approval delayed | | No decision by week 5 | Start non-human-data workstream; move study later |
| Scope creep | | Any new "must" after week 2 | New must displaces an old one, in writing |
| Hardware/compute dies | | Any loss > 2 days | Pre-priced cloud fallback; daily off-machine backups |
| Supervisor latency | | 2 meetings missed | Written status memo; escalate per department norms |
| Teammate vanishes | | 2 weeks non-delivery | Drop pre-agreed shoulds; re-partition musts |
